Chapter 1 · Factorials

n! (read “n factorial”) is the product of all whole numbers from n down to 1. Every counting formula in this book is built from factorials, so get fluent with them first.

1.1 The Factorial Table

0! = 1. There is exactly one way to arrange nothing. Factorials are defined only for whole numbers 0, 1, 2, 3 …

1.2 Rules for Working with Factorials

RuleFormExample
Peel off one termn! = n × (n − 1)!7! = 7 × 6!
Peel off moren! = n(n − 1)(n − 2)!10! = 10 × 9 × 8!
Divide by cancellingn!/(n − r)! = n(n − 1)…(n − r + 1)9!/6! = 9 × 8 × 7 = 504
One step apartn!/(n − 1)! = n12!/11! = 12
No shortcut for + or ×(a + b)! ≠ a! + b!3! + 2! = 8, but 5! = 120

1.3 Solving for n

  1. Write the bigger factorial down to the smaller one: (n + 2)! = (n + 2)(n + 1)n × (n − 1)!
  2. Cancel the common factorial from both sides.
  3. You are left with a product of consecutive numbers. Spot it from the table below.

1.4 Worked Examples

Example 1. Evaluate 12! / (10! × 2!).
= (12 × 11 × 10!) / (10! × 2) = 132 / 2
→ 66
Logic: Peel 12! down to 10! and cancel. Never multiply out a large factorial.
Example 2. Solve (n + 1)! = 20 × (n − 1)!.
(n + 1) × n × (n − 1)! = 20 × (n − 1)! ⇒ (n + 1)n = 20 = 5 × 4
→ n = 4
Logic: After cancelling, (n + 1)n is two consecutive numbers. The pair with product 20 is 4 and 5.
Example 3. Find x if 1/4! + 1/5! = x/6!.
Multiply every term by 6!: 6!/4! + 6!/5! = x ⇒ 30 + 6 = x
→ x = 36
Logic: Multiplying by the largest factorial clears every denominator: 6!/4! = 6 × 5 = 30 and 6!/5! = 6.

1.5 Common Mistakes to Avoid

  • (3!)! means 6! = 720. Work the inner bracket first.
  • 0! = 1, not 0.
  • 10!/5! is not 2!. It is 10 × 9 × 8 × 7 × 6 = 30240.
  • 2 × 3! = 12, but (2 × 3)! = 6! = 720.

Chapter 2 · The Fundamental Principle of Counting

Two rules do most of the work in this topic. Ask one question every time: must I do this and that, or this or that?

2.1 AND Multiplies, OR Adds

RuleWhenCountExample
Multiplication (AND)The job is done in stages, one after anotherm × n5 shirts and 3 trousers → 5 × 3 = 15 outfits
Addition (OR)The choices are alternatives; you pick only onem + n3 buses or 2 trains → 3 + 2 = 5 ways to travel

2.2 The Slot Method

Draw one box for each decision. Write the number of choices in each box, then multiply. Fill the most restricted box first.

A meal of 1 starter (4 choices), 1 main (5 choices) and 1 dessert (3 choices):
4×5×3=60
Logic: Starter AND main AND dessert, so multiply the three boxes.

2.3 Worked Examples

Example 1. There are 3 roads from A to B and 2 roads from B to C. In how many ways can you go from A to C through B?
A → B: 3 ways, AND B → C: 2 ways ⇒ 3 × 2
→ 6
Logic: Every road to B can be followed by every road to C.
Example 2. Same roads. How many round trips A → C → A are possible if no road is used twice?
Going: 3 × 2 = 6. Returning: C → B has 1 road left, B → A has 2 left ⇒ 1 × 2 = 2. Total 6 × 2
→ 12
Logic: The return trip loses the roads already used. If any road may repeat, the answer is 6 × 6 = 36.
Example 3. A suitcase lock has 3 dials, each showing 0 to 9. How many codes are possible?
10×10×10=1000
Logic: Digits can repeat on different dials, so every dial has all 10 choices.

2.4 Common Mistakes to Avoid

  • Adding when the job has stages. A shirt and a trouser is 3 × 4, not 3 + 4.
  • “Return by the same route” leaves only 1 choice for the return, not 4.
  • “Return by a different route” removes only the route used going, so 4 routes leave 3.

Chapter 3 · Forming Numbers from Digits

Each digit place is a slot. Before you start, read two things in the question: can digits repeat, and is 0 one of the digits?

3.1 Repetition Allowed or Not

SituationSlotsr-digit numbers from n non-zero digitsExample: 3-digit from 1–6
No repetitionChoices drop by 1 each slotn(n − 1)(n − 2)… = ⁿPᵣ6 × 5 × 4 = 120
Repetition allowedEvery slot gets every digitnʳ6 × 6 × 6 = 216

3.2 The Zero Rule

A number cannot start with 0 (057 is a 2-digit number). When 0 is among the digits, fill the first slot first, leaving 0 out. After that, 0 is allowed.

4-digit numbers from 0, 2, 4, 6, 8 with no repetition:
4×4×3×2=96
Logic: First slot: 2, 4, 6 or 8 (4 ways). Second slot: 0 is now allowed, and one digit is used, so 4 ways. Then 3, then 2.

3.3 Numbers with a Condition

ConditionControlsFill first
EvenLast digit is 0, 2, 4, 6 or 8Last slot
OddLast digit is 1, 3, 5, 7 or 9Last slot
Divisible by 5Last digit is 0 or 5Last slot
Greater than / betweenThe first digitFirst slot
0 among the digitsThe first digit is not 0First slot
Order of filling: restricted slots first, free slots last. When the last digit could be 0 and the first digit cannot be 0, split into two cases: last digit 0, and last digit not 0.

3.4 Worked Examples

Example 1. How many 3-digit even numbers can be formed with 1, 2, 3, 4, 5 if no digit repeats?
4×3×2=24
Logic: Last slot first: 2 or 4 (2 ways). First slot: any of the 4 digits left. Middle: 3 left.
Example 2. How many 3-digit numbers greater than 500 can be formed with 2, 4, 5, 7, 9 if no digit repeats?
3×4×3=36
Logic: First digit must be 5, 7 or 9. A number starting with 5 is at least 524 here (there is no 0), so all of them are above 500.
Example 3. How many 3-digit even numbers can be formed with 0, 1, 2, 3, 4 if no digit repeats?
Case 1, last digit 0: 4 × 3 × 1 = 12
Case 2, last digit 2 or 4: first slot 3 ways (not 0, not the last digit) × middle 3 ways × 2 = 18
→ 12 + 18 = 30
Logic: The last digit can be 0 and the first cannot, so the cases are counted separately and added (OR rule).

3.5 Common Mistakes to Avoid

  • Letting 0 sit in the first slot. Always fix the first slot when 0 is available.
  • Filling slots left to right when the condition is on the last digit. Fill the last digit first.
  • Using nʳ when the question says “digits cannot be repeated”, or the reverse.

Chapter 4 · Arranging the Letters of a Word

Arranging letters is the slot method with one slot per letter. Repeated letters and “together” conditions each need one extra step.

4.1 The Four Situations

SituationMethodExample
All letters differentn!CAT → 3! = 6: CAT, CTA, ACT, ATC, TCA, TAC
Some letters repeatn! / (p! q! …)LEVEL (L×2, E×2) → 5!/(2! × 2!) = 30
Fixed positionsFill the fixed places first, then arrange the restMONDAY starting with M → 5! = 120
Some letters togetherGlue them into one block, arrange the blocks, then arrange inside the blockORANGE, vowels together → 4! × 3! = 144
Why divide for repeats? In LEVEL, swapping the two L’s gives the same word. Each word was counted 2! times for the L’s and 2! times for the E’s, so divide by 2! × 2!.

4.2 The Glue Method, Step by Step

  1. Count the letters and note any that repeat.
  2. Glue the letters that must be together into one block.
  3. Arrange the block with the other letters. Divide for any repeats outside the block.
  4. Multiply by the arrangements inside the block. Divide for repeats inside it.
ORANGE, all vowels together. Vowels O, A, E; consonants R, N, G.
OAERNG
4 units → 4! = 24; inside the block → 3! = 6; 24 × 6 = 144
Logic: For “vowels not all together”, subtract from the total: 6! − 144 = 576.

4.3 Worked Examples

Example 1. In how many ways can the letters of MONDAY be arranged so the word begins with a vowel and ends with a consonant?
243214
First: O or A (2). Last: M, N, D or Y (4). Middle 4 letters: 4! = 24. 2 × 4 × 24
→ 192
Logic: Fill both fixed places first, then arrange whatever is left in the middle.
Example 2. In how many ways can the letters of BALLOON be arranged so the two L’s are together?
BALLOON: 7 letters, L×2, O×2. Glue LL → units B, A, [LL], O, O, N = 6, with O twice. 6!/2! = 720/2
→ 360
Logic: The block LL has only 1 inside arrangement (identical letters). Divide by 2! for the two O’s outside it.

4.4 Common Mistakes to Avoid

  • Forgetting to multiply by the arrangements inside the block.
  • Missing a repeated letter. Write each letter with its count before you start.
  • Counting “starts with a consonant” as 1 way. It is the number of consonants available.

Chapter 5 · ⁿPᵣ and ⁿCᵣ

Arrangement or selection? That single question decides between permutation and combination.

5.1 Permutation vs Combination

Permutation ⁿPᵣCombination ⁿCᵣ
MeaningArrange r out of n things (order matters)Select r out of n things (order does not matter)
Formulan! / (n − r)!n! / [r! (n − r)!]
ExamplePresident and secretary from 10 people: ¹⁰P₂ = 90A 2-person team from 10 people: ¹⁰C₂ = 45
Key wordsarrange, order, rank, digits, positions, postsselect, choose, team, committee, group
Quick test: swap two of the chosen items. If it gives a new outcome, use P. If it gives the same outcome, use C. And always ⁿPᵣ = ⁿCᵣ × r!.

5.2 Fast Calculation

To findDo thisExample
ⁿPᵣStart at n and multiply r numbers going down⁸P₃ = 8 × 7 × 6 = 336
ⁿCᵣSame r numbers on top, r! below⁸C₃ = 336 / 6 = 56
ⁿCᵣ, large rUse the smaller of r and n − r²⁰C₁₈ = ²⁰C₂ = 190

5.3 Properties to Memorise

PropertyExample
ⁿP₁ = n, ⁿPₙ = n!, ⁿP₀ = 1⁶P₆ = 720
ⁿC₀ = ⁿCₙ = 1, ⁿC₁ = n⁹C₉ = 1, ⁹C₁ = 9
ⁿCᵣ = ⁿCₙ₋ᵣ¹⁰C₈ = ¹⁰C₂ = 45
If ⁿCₓ = ⁿCᵧ, then x = y or x + y = nⁿC₃ = ⁿC₅ ⇒ n = 8
ⁿCᵣ + ⁿCᵣ₋₁ = ⁿ⁺¹Cᵣ⁵C₂ + ⁵C₁ = ⁶C₂ = 15

5.4 Worked Examples

Example 1. If ⁿP₃ = 6 × ⁿP₂, find n.
n(n − 1)(n − 2) = 6 × n(n − 1) ⇒ n − 2 = 6
→ n = 8
Logic: Cancel the common factors n(n − 1). Only the extra factor is left.
Example 2. If ⁿC₂ = 28, find n.
n(n − 1)/2 = 28 ⇒ n(n − 1) = 56 = 8 × 7
→ n = 8
Logic: The same “consecutive product” trick from Chapter 1.
Example 3. If ⁿC₄ = ⁿC₆, find ⁿC₂.
4 ≠ 6, so n = 4 + 6 = 10. ¹⁰C₂ = (10 × 9)/2
→ 45
Logic: Equal combinations with different lower numbers means the lower numbers add up to n.
Example 4. A committee of 3 men and 2 women is chosen from 7 men and 4 women. How many committees are possible?
⁷C₃ × ⁴C₂ = 35 × 6
→ 210
Logic: Choose the men AND choose the women, so multiply. A committee has no order, so use C.

5.5 Common Mistakes to Avoid

  • Using P for a team or committee. Members of a team have no order.
  • From ⁿCₓ = ⁿCᵧ, writing only x = y. When x ≠ y, the answer is n = x + y.
  • Working out ¹⁵C₁₃ the long way. Use ¹⁵C₂ = 105.
